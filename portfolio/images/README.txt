# Portfolio de Laobe SENE

Version de base complète du portfolio violet/lavande.

## Fichiers
- `index.html` : contenu et sections
- `style.css` : design responsive et animations
- `script.js` : filtres, fenêtres de détail, mini-démonstrations et formulaire mailto
- `documents/` : place ici le vrai CV PDF et tes lettres de motivation
- `images/` : place ici les captures authentiques de tes projets

## Démarrer
1. Décompresse le ZIP.
2. Ouvre le dossier `portfolio_laobe_sene` dans VS Code.
3. Ouvre `index.html` dans un navigateur. Pour un rechargement pratique, tu peux utiliser l'extension Live Server.

## À personnaliser avant publication
1. Ajoute ton vrai CV sous le nom `documents/cv-laobe-sene.pdf`, ou modifie le chemin dans `index.html`.
2. Ajoute tes lettres PDF dans `documents/lettres-motivation/`. Le lien actuel ouvre le dossier local, il faudra remplacer ce lien par les vrais fichiers PDF nommés.
3. Remplace les visuels illustratifs par des captures réelles. Les dossiers d'images sont préparés pour chaque projet.
4. Remplace le lien `https://github.com/` par l'URL exacte de ton profil GitHub après l'avoir vérifiée.
5. Les descriptions sont volontairement générales pour ne pas inventer de fonctionnalités. Complète chaque fiche à partir de tes applications réelles.
6. Le formulaire de contact ouvre le logiciel de messagerie via `mailto:` ; il n'envoie pas de message sur un serveur.

## Démonstrations
Les mini-démos intégrées sont des simulations pédagogiques locales. Elles ne prétendent pas exécuter les applications Android ni se connecter à GESTICOM. Pour une démo réelle, ajouter une version web testée ou une vidéo/capture issue du vrai projet.

## Publication
Avant de publier sur GitHub Pages ou un autre hébergeur, vérifie les liens de documents, l'absence de données personnelles non souhaitées et l'absence de secrets dans le code.
